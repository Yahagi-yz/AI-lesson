Skill / Flow 速查

需要快速判断“我现在该做什么”时，看这一页。

Skill = 一个具体工程能力。
Flow = 多个 Skills 组成的整体工程路径。

判断顺序

1. 当前处于什么工程阶段？ 2. 当前缺的是：决策 / 运行证据 / 规格 / 实现 / 诊断 / 审查？ 3. 选择当前阶段对应的 Skill。 4. 完成后再判断是否进入下一阶段。

常见路由提示

需求或设计没对齐 → grilling / grill-with-docs

必须跑起来或看见才能回答设计问题 → prototype

shared understanding 已形成，要固化规格 → to-spec

规格太大，需要拆为可执行工作 → to-tickets

大型、多会话工作，连路径都不清楚 → wayfinder

开始构建 → implement（内部结合 tdd / code-review 等）

已有故障但原因不明 → diagnosing-bugs

一句话检查

如果你发现自己在问“哪个 Skill 最厉害？”，改问：

“当前工程阶段缺的到底是什么？”
