Grilling Exit Gate

什么时候可以结束 grilling？

1. 还有未决 decision？ yes → 继续 grilling no ↓ 2. 是否存在静默假设 / 未访问分支？ yes → 重新打开 design tree no ↓ 3. 总结 shared understanding ↓ 4. 用户明确确认？ no / 修正 → 重算 design tree yes → grilling 结束

frontier = ∅ 是必要条件，不是行动授权。

常见错误

错误 1：“问题问完了，所以我开始实现。”

纠正：先让用户确认 shared understanding。

错误 2：摘要阶段用户提出修正，但 AI 只修改文案，不重新计算依赖。

纠正：修正可能重新打开 design tree，必须重算 frontier。

错误 3：为了尽快结束，把未问到的约束当默认值。

纠正：frontier 真正为空意味着没有留下静默假设。
