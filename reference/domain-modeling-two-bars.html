Domain Modeling · Two Write Bars

“是什么” → CONTEXT.md；“为什么选这个高成本方案”且三 gate 全过 → ADR。

CONTEXT.md

写：项目特有领域概念、简短定义、概念关系、Avoid 同义词 不写：实现细节、spec、scratch notes、数据库/函数/API 细节

ADR

必须同时满足： 1. Hard to reverse 2. Surprising without context 3. Real trade-off 任一项 = No → Skip ADR

快速路由

Run = Task 的一次执行 → CONTEXT.md 核心写模型选择 event sourcing 而非 CRUD， 有真实替代、迁移昂贵、理由无法从代码直接看出 → ADR 失败重试 3 次 / 函数命名 / 临时配置 → Neither
