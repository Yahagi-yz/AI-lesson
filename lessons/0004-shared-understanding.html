AI Lesson · Stage 1

Lesson 0004 · Shared Understanding 与结束条件

单一目标：判断一次 grilling 什么时候真的可以结束，以及为什么 frontier 清空后仍不能直接行动。

速查：Grilling Exit Gate 课程地图
本课完成标志

你能区分“继续 grill”“总结并等待确认”“已可离开 grilling”三种状态。

1. Frontier 清空只是第一个 gate

Matt 的规则不是“没问题可问了就开始做”，而是：frontier 为空意味着 design tree 已经走完，每个分支都访问过，没有留下静默假设。

Gate 1：Design tree exhausted frontier = ∅ 所有分支已访问 没有静默假设 ↓ 仍然不能行动

2. 第二个 gate：用户确认 shared understanding

当 frontier 为空，AI 应该把已经形成的共同理解压缩成清晰摘要，让用户检查自己是否真的同意。

Gate 1 通过 ↓ AI 总结 shared understanding ↓ 用户明确确认？ ├─ No / 有修正 → 重新打开 design tree └─ Yes → Grilling 结束

Frontier empty ≠ permission to act.
User confirms shared understanding → 才能离开 grilling。

3. 用户一旦修正，树会重新长出来

假设所有问题都问完了，AI 总结：“失败后自动重试 3 次。”用户说：“等等，生产环境不能自动重试。”这不是简单改一句摘要，而是产生了新的 decision branch。

原 frontier = ∅ ↓ 用户修正 shared understanding ↓ 新 decision 出现 ↓ 重新计算 frontier ↓ 继续 grilling

4. Retrieval practice

Q1. 还有一个依赖已满足的 decision 没问。现在？
Q2. 所有分支已解决，没有静默假设，但用户还没确认。现在？
Q3. 用户在确认摘要时新增了一个约束。现在？

5. 一句话记忆

Grilling 的结束不是“AI 没问题了”，而是“树已穷尽 + 用户确认共同理解”。
