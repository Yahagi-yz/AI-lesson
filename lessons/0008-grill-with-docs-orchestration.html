Lesson 0008 · grill-with-docs：Stateful Alignment Orchestration

单一目标：监督 grill-with-docs 是否真的同时运行了 grilling 与 domain-modeling，并正确理解这场 stateful session 的 paper trail。

速查：Orchestration Map 上一课 课程地图
本课完成标志

你能判断何时该由用户主动调用 /grill-with-docs，解释它为何必须同时加载两个 Skills，并发现“只 Grill 不写 docs”“把所有决定都写 docs”等 orchestration 错误。

1. 它不是第三套算法，而是两个已掌握能力的组合

官方 grill-with-docs/SKILL.md 的核心只有一句：调用 Skill tool 两次，分别加载 grilling 和 domain-modeling。

用户主动 /grill-with-docs ↓ Skill call #1 → grilling design tree / frontier / facts / shared understanding + Skill call #2 → domain-modeling vocabulary / scenarios / code cross-check / docs ↓ stateful alignment against a repo

grill-with-docs = interview engine + domain model discipline + real repo state。

2. 为什么它和 grill-me 不一样？

无 repo / 不需要写文件 → /grill-me → grilling only → stateless 有 repo + change 仍模糊 + 单会话能澄清 → /grill-with-docs → grilling + domain-modeling → stateful 工作大到单会话装不下 → wayfinder

因此，grill-with-docs 也是 user-invoked：是否进入这场会修改真实仓库文档的对齐过程，由用户决定。

3. Stateful 不等于“把所有答案都写文件”

一场 session 的结果有三类，而且只有前两类真正落盘：

Resolved term → CONTEXT.md → 术语一确定就立即写 Hard decision that passes all 3 ADR gates → docs/adr/NNNN-*.md Everything else decided → conversation only → 不塞进 CONTEXT.md，也不滥写 ADR

这正是为什么 session 结束后不能随手清空上下文：大量普通 decisions 仍然只存在当前 conversation 中。

4. 正常下一步：沿用同一个 conversation

grill-with-docs → shared understanding confirmed → CONTEXT.md / ADR 已按规则增量更新 → 普通 decisions 仍在 conversation → 同一 conversation → to-spec

Durable docs 不是完整 spec。不要把“写了 CONTEXT.md/ADR”误解为“所有需求已经持久化”。

5. 最值得监督的 partial-loading failure

官方文档特别指出：常见失败不是完全没运行，而是只加载了一半。

只加载 grilling → Round/frontier 很漂亮 → 但术语确定后 CONTEXT.md 一直不变 → orchestration failure 只执行 domain-modeling → 有 glossary / ADR 动作 → 但没有完整 design tree/frontier inquiry → orchestration failure

因此监督 grill-with-docs 时，不要只看“它有没有问很多问题”，也不要只看“它有没有写文件”；要看两个 primitive 是否同时在工作。

6. Retrieval practice

Q1. /grill-with-docs 正确启动后，底层应该加载什么？
Q2. 哪个场景最适合 /grill-with-docs？
Q3. “失败后重试 3 次”已经在 grilling 中确认，但不属于 glossary，也不过 ADR gate。它默认去哪？
Q4. 问题轮次和 frontier 都正常，但术语已经确定，CONTEXT.md 仍从未更新。最应怀疑？
Q5. grilling 结束并确认 shared understanding 后，正常进入 to-spec 时应该？

7. 一句话记忆

/grill-with-docs = 用户主动启动的 stateful front door：grilling 把问题问清，domain-modeling 把该落盘的语言和少数硬决策即时落盘；其余共识继续由同一会话带给 to-spec。
