# AI Lesson

这是一个使用 Matt Pocock `teach` 方法维护的长期 AI 工程学习 workspace。

## Mission

学习 `mattpocock/skills`，目标不是背命令，而是在 Codex / AI 软件工程中能够识别工程阶段、选择和组合正确的 Skill / Flow，并监督 AI 是否跳步、误用或遗漏关键工程环节。

## Teaching rule

核心 Skill 只有在学习者能做到以下四项后，才算 mastered：

1. 识别何时用、何时不用。
2. 解释核心机制。
3. 在案例中正确使用。
4. 发现 AI 用错并纠正。
